## Requested Work

The proposal describes OpenRPC as an Apache 2.0 standard and tool ecosystem for
machine-readable JSON-RPC API specifications. It requests funding for two
engineering deliverables:

1. A production-ready linter with stable releases, CI, documentation, examples
   and a recommended ruleset.
2. Modernization of the test-coverage tool as an ESM module, including regression
   tests, migration guidance and CI integration documentation.

The proposal reports more than 5.9 million TypeScript/NPM toolkit downloads in
the preceding year and lists multiple blockchain ecosystems as adopters. This
capture preserves that as a source-reported claim, not an independently
reproduced metric.
